## Genomica comparativa.

Bienvenido a este repositorio. En él encontrarás el contenido practico del curso de Genómica Comparativa de la licenciatura en Ciencias Agrogenómicas de la UNAM.

En los contenidos del repositorio hay un directorio para cada tema que veremos en clase. Dentro de estos directorios se encontraran ordenados subdirectorios de las diferentes actividades que realizaremos en cada tema. Finalmente, dentro de cada actividad habrá una carpeta para scripts llamada `bin`, los archivos input de entrada en `data` y los archivos de salida en `results`. Esta estructura permite que si clonas o descargas este repositorio podrás seguir cada una de las actividades de los análisis que realizaremos en orden y seguir el "pipeline" completo desde los datos crudos de entrada hasta gráficas y resultados finales.

Como ejemplo de la estructura de este repositorio, aquí puedes ver la estructura de directorios de la primera actividad que realizaremos correspondiente al tema de **Filogenómica**:

```
01_Filogenomica/
├── 01_Download_Fasta_Files
│   ├── bin
│   ├── data
│   │   └── Access_Codes
│   └── results
├── 02_Alineamientos
│   ├── bin
│   └── results
│       ├── 01_Aligned
│       ├── 02_Aligned_Named
│       ├── 03_Aligned_Edited
│       └── 04_Aligned_Concatenated
└── 03_Filogenias
    ├── bin
    └── results
        ├── 01_modeltest
        └── 02_raxml

```

Adicionalmente en el directorio principal de cada tema encontrarás las diapositivas de cada tema y una breve explicación del análisis que realizaremos.
